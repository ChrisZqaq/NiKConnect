# NP3 文件格式逆向笔记（2026-11-12）

来源：Timor88/NikonNP3 仓库 32 个样本 hex 分析；字节级重组验证 32/32 通过。

## 总体布局（两种尺寸：392B / 978B）

```
0x00  4B   魔数 "NCP\0"
0x04  4B   0000 0100（版本）
0x08  4B   0000 0004
0x0C  4B   "0310"（格式串）
0x10  4B   0000 0200
0x14  4B   0000 0014（=20，name 长度）
0x18  20B  方案名（picture_controll_name，\0 填充）
0x2C  2B   0000
0x2E  ...  TLV 参数区（见下）
tail  ...  392 版: "0000" 结束
           978 版: 色调曲线块（见下）+ "0000 0000" 结束
```

## TLV 记录（参数区，0x2E 起）

每条：`tag u8 + 3B 00 + len u16(BE) + val[len] + 2B 00`（len=2 时记录 10B）
tag 3..0x1E 恒 len=2（val u16 大端）；tag 0x1F len=28（基准曲线 28B）；tag 0x20 len=20（色相调优表 20B）。

tag 语义（部分推断，待 detail API 对照确认）：
- 0x03: 0x0020（32）——Picture Control 模式/类型号
- 0x05..0x18: 锐化/中锐/清晰度/对比度/饱和度等（值如 ff01/8804/8204）
- 0x19..0x1E: 色彩扩展 6 项（值 x001，hi 字节 -127..+127，0x80=0）
- 0x1F: 28B 基准曲线锚点（如 9480858a807b767b7ea36260a8995876717b854e85bc718a010101000000）
- 0x20: 20B 色相调优表（如 806487808000808080199480010101009e018001）

## 978B 版尾部：自定义色调曲线（"BI0" 块）

```
00 02 00 00 02 "BI0" + 13B 头（00 ff 00 ff 01 00 06 00 00 2f 13 54 40 82 96 bd d7 ff ff）
+ 零填充至 0x4A
+ 曲线点表：u16 BE 递增序列（57..0x7fff，253 点，单调）
+ 0000 0000
```
392B 版无 BI0 块 → 相机用方案默认曲线。

## 关键结论

- NP3 = 头部模板 + ~29 个参数/表字段 +（可选）自定义曲线。
- **参数与官网 detail API 的 pictureControl 字段一一对应**（待恢复后逐 tag 标定）。
- 生成器：参数 → TLV 组装 → 字节级验证（重组 32/32 与原文件完全一致，解析器无损）。
- detail API（/bff/recipe/release/detail）自 2026-11-12 14:2x 起返回 E01_9999（疑似服务端故障，零登录 header 有效格式已验证：Content-Type text/plain;charset=UTF-8，body 字段全字符串）。
