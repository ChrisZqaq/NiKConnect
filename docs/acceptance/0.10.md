**硬件/系统事实（写进文档避免再踩）**

1. **这台机器的 navigationBars inset 恒为 0**：`adb shell dumpsys window \| grep navigationBars` → `InsetsSource id=a2990001 type=navigationBars frame=[0,2376][1080,2376] visible=true ... mSurfacePosition=Point(0, 2244)`。frame 起点终点同一 y；手势条实际在 2244。所有依赖 inset 的写法（`navigationBarsPadding()`、`decorFitsSystemWindows=false`、`maxOf(inset, 36.dp)`）在这台机器上都不会移动任何像素 → 最终改用「加法保底 + 真实 `Spacer` 占位」。
2. **App 内点「断开」会让相机自己关掉热点**；`adb install` 杀进程同样会被相机判定为断联并关闭热点。⇒ 每次装包后都需要在机身「连接至智能设备 → Wi-Fi 连接」重开一次。
3. **相机 PTP 会话异常结束后约 60 s 才释放**，强杀后立刻重连必失败。
4. `nc -z` 探 15740 会干扰相机（连续 4 次结果 `0/1/0/1`），不要用它判断"相机是否在线"。
5. APK 体积长期恒为 57,598,524 字节，**不能用大小判断版本**；用 `adb shell dumpsys package com.chrisz.nikconnect.debug | grep versionName`。
