# 开发进展

最后更新：2026-10-29

## 当前结论

MVP 核心链路已经由用户在真机上手动验证：连接 Nikon Zf、读取照片列表、显示缩略图并下载 JPEG 原图到手机。

当前开发版本是 `0.1.1`。`0.1.0` Release 中提供调试签名的 APK，用于个人测试，不是正式发行构建；`0.1.1` 尚未发布，也尚未进行真机验收。

## 已验证

- 手机可以接入相机热点，应用可以完成 PTP/IP 初始化与会话建立。
- 用户确认相机使用「连接至智能设备 → Wi-Fi 连接」，README 已与 App 引导对齐。
- 可以获取照片列表和缩略图。
- 可以下载 JPEG 原图。
- 0.1.1 的 19 项 JVM 单元测试通过，`lintDebug` 与 `assembleDebug` 构建通过。
- 0.1.0 已完成核心链路的真机手动验证；0.1.1 的修复仍待真机回归。

上述真机结果来自 0.1.0；0.1.1 新增测试覆盖会话失效、握手取消和残片清理。尚未重新连接手机或相机，不能据此宣称 R1–R4 已完成真机验收。

2026-10-29 的代码审查基线为 `2bc3f43`。已知风险与验收标准见 [MVP 审查与后续开发](ZF_Relay_MVP审查与后续开发.md)。

尚未建立连接真实相机的自动化测试；其他相机、手机和固件组合未验证。

## 已解决的问题

- 修正 PTP 数据方向常量，避免读取流程使用错误的数据阶段。
- 修正照片信息字段偏移，避免文件名和日期解析错位。
- 校验事务编号；超时或读包失败后关闭通道，避免串用上一次请求的数据。
- 补充备用网络流程所需的 `CHANGE_NETWORK_STATE` 权限。
- 按连接隔离下载断点，避免换卡或格式化后误续写到旧文件。
- 移除握手前会立即关闭的空 TCP 探测；该改动后的版本已通过真机连接验证。
- 增加握手分阶段错误信息，缩短真机问题定位时间。
- 精简界面文案与操作路径。

## 已知问题与限制

### 连接与后台

- R1–R4 已完成代码修复，但连接生命周期和任务归属仍须按验收场景进行真机回归。
- 用户观察到切到后台后可能断连，具体诱因尚未在真机上分离验证。
- 没有后台下载保活，切后台或系统回收进程可能中断任务。
- 没有自动重连；跨连接续传也不支持，重连后需要重新下载。
- 尚未系统验证相机空闲超时、锁屏和一加后台策略对连接的影响。

### 照片与任务

- 目前只支持下载 JPEG，不支持 NEF RAW 下载。
- 一次只能下载一张照片，没有批量队列、取消或完成通知。
- 每次最多读取最近 120 个对象，不支持完整图库分页。
- 缩略图仅使用内存缓存，没有磁盘缓存。
- 尚未验证超大文件、存储空间不足、换卡及大规模连拍等边界场景。

### 发布与质量

- 当前 APK 为调试签名版本，尚无正式发布签名与版本升级策略。
- 真机验证目前依赖手动操作，没有可持续运行的设备回归测试。

## 下一阶段优先级

1. 0.1.1：完成 R1–R4 真机验收，验证单张与连续下载文件完整性、退出和断线恢复。
2. 0.2：多选、串行批量队列、取消与图库加载更多。
3. 0.3：前台服务持有传输任务，验证后台与锁屏行为。
4. 0.4：NEF 原文件、性能对照与发布签名/升级验证。

各阶段的具体任务、验收门槛和真机记录模板见 [后续开发计划](ZF_Relay_MVP审查与后续开发.md)。版本号为建议，不代表已经排定发布日期。

实时取景、远程快门和参数控制暂不纳入当前阶段，优先保证传图链路稳定。
